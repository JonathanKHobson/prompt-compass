# Prompt Compass

## Historical repository

This repository preserves the earlier public guide and downloads. Current methods
and onboarding live in [Prompt Playbook Studio](https://github.com/JonathanKHobson/working-tools-plugins/tree/main/plugins/prompt-playbook-studio).
Existing Pages URLs, release assets, checksums and examples remain available.

The documentation below describes the preserved edition. Archival does not remove
separately configured runtimes, change their data, or make the successor a bundled
replacement for every historical backend.

Prompt-building tools and installation guidance. Start with the [public guide](https://jonathankhobson.github.io/prompt-compass/) or the versioned Releases.

This repository hosts the public Prompt Compass download page at
https://jonathankhobson.github.io/prompt-compass/.

Install files are published as GitHub Release assets for `v0.1.0-beta.3`.
The `downloads/checksums.txt` file is included for verification.

## Source and contribution boundaries

This repository owns the public landing page, installation guidance, and preserved download copies. It is not the complete maintained runtime workspace. Use a versioned source package when a release provides one; do not reconstruct a package from the landing page. The current public release remains usable on its documented terms while successor packaging is separate work.

For a website change, edit the page and its local assets, preview the affected route, and verify downloads and shared Compass navigation. For a package change, locate the owning source and reproduce that release before changing distribution links. Preserve existing versioned assets and checksums. See [AGENTS.md](AGENTS.md).
